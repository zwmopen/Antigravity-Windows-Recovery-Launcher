## 🎯 v2.9.29 重点打磨了什么？（直击体感细节）

1. **🔄 加上“旋转小圆圈加载状态”，干活进度一眼可见**
   - 热启动卡片在异步读取软件内当前账号期间，旁边新增顺滑旋转的蓝色加载圆环，不再干巴巴只有静态文字；
   - 5 步启动自检卡片（`当前账号 → 本地专线 → Google 通路 → AI 模型验证 → 启动工作区`）正在执行的步骤圆圈外围也加上旋转加载光环，跑哪一步转哪一步，完成后立刻变绿勾。

2. **🧹 顶部栏彻底瘦身，告别乱七八糟的重叠小徽标**
   - 去掉之前顶部多余的 `· 待验证`、`PRO · 额度充裕`、`编辑器运行中` 三个小胶囊徽标，不再与右上角的设置齿轮 `⚙` 挤撞遮挡；
   - 顶部只清爽保留左侧图标 + `Antigravity`，以及右侧独立舒展的 `⚙`（设置）、`—`（最小化）、`×`（关闭）。

3. **📐 高分屏设置弹窗（⚙）重排，不再文字挤叠或冒方框**
   - 给 `LauncherSettingsForm` 补齐 `100% / 150% / 200%` DPI 自适应缩放，扩展弹窗尺寸与控件留白，去掉会在微软雅黑字体下变方框 `▯` 的 Emoji；
   - 点开右上角齿轮图标后，所有开关说明和分屏按钮齐整舒展、零遮挡、零截断。

4. **⏱️ 确保足额 5 秒完整倒计时**
   - 以前后台读取当前账号耗去约 1.8 秒时，倒计时其实已经在偷偷走表，等文字出来只剩 ~3 秒；
   - 现在会在读取并展示完当前账号、状态评估与专线结果后，再正式开启完整 **5 秒**倒计时（副标题同步写明“点击空白处可暂停 5 秒倒计时”）。

5. **📖 人类直觉文案：`Pro`、`5 小时`、`周`**
   - 账号信息改为更自然清晰的 `Pro · 5 小时 75% | 周 30%`（首字母大写的 `Pro` + 中文 `5 小时` / `周`），5 步启动胶囊也同步升级。

6. **🛰️ 一开始就直显“状态评估”与真实“线路节点名称”**
   - `⏳ 状态评估` 与 `✅ 状态评估` 从开屏就保持结构完整；
   - `Write-PrivateConfig` 写入配置时同步保留 `# Antigravity-Target-Node` 与 `# Antigravity-Target-Region` 元数据，启动器也会根据活跃 `server + port` 从本机 Clash/Mihomo 配置文件毫秒反查真实节点名称并并行轻测 `17897` 真实延迟（例如 `线路  美国 · 美国凤凰城|hy2（在线 · 286ms）`），彻底告别“节点名称待同步”与“· 待验证”。
