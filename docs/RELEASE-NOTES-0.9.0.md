# 0.9.0 发布说明

## 这次解决什么

0.9.0 把原来的 ZIP + `Install.cmd` 升级为普通 Windows 用户熟悉的单文件中文安装向导，同时保留 ZIP 备用包；并修复桌面启动与后台自愈同时发生时的 `supervisor_run_busy` 误报。

## 用户怎么安装

1. 下载 `Antigravity-Windows-Recovery-Setup-0.9.0-windows-x64.exe`。
2. 双击运行，在“目标文件夹”中直接粘贴路径，或点击“浏览”选择目录。
3. 点击安装。首次安装若本机没有官方 `agy`，会下载约 188 MB 的 Google 官方组件并校验 SHA-512，可能需要几分钟。
4. 完成页可勾选“立即启动”或“打开安装目录”。
5. 以后只双击桌面的 `Antigravity 启动器`。

## 升级与卸载

- 再次运行 Setup 会复用上次安装路径，也允许重新选择。
- 可在 Windows“已安装的应用”中卸载。
- 卸载不会删除 Antigravity 登录态、会话、项目、Clash 订阅和私人代理运行数据。

## 备用安装方式

完整解压 ZIP 后双击 `Install.cmd`，会安装到默认目录并创建同一个桌面入口。

## 已知边界

- Setup.exe 当前未做商业代码签名，Windows SmartScreen 可能显示未知发布者；可通过 Release 页 SHA-256 校验完整性。
- 安装包不携带 `agy.exe`、代理节点或私人配置；首次安装需要网络。
- 本工具不修改 Clash 的模式、日常节点或 `127.0.0.1:7897`。
- 如果你在后台自愈进行时再次双击桌面入口，启动器会等待后台结果；只有真实检查失败才会提示错误。
