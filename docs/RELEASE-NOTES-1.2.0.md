Antigravity 智能启动器迎来 **1.2.0 正式版**里程碑！
本次发布彻底解决了多账号环境下额度触顶时切号中断、需手动干预的痛点，实现了**“全链路脱壳闭环、在线秒级切号先行、磁盘状态机事务自愈与专线订阅透明化”**的真正全自动无人值守体验。同时，项目正式完成向单一权威公开开源仓库的收拢。

## 🌟 核心突破与重磅特性

### 1. 彻底终结切号中断：全链路脱壳与零风险时序
- **切号生命周期与进程树彻底脱耦**：守护神看门狗与自愈拉起动作全面接入 `CREATE_BREAKAWAY_FROM_JOB`、`DETACHED_PROCESS` 与 WMI 脱壳派生机制，完全脱离宿主编辑器的进程树，彻底根除“杀编辑器时看门狗被操作系统连带清理”的致命缺陷；
- **在线秒级切号先行**：摒弃先强杀编辑器的粗暴逻辑，改为在 Antigravity 运行状态下直接向 Cockpit WebSocket 发送切号指令（无损修改凭据与 accounts.json），再由启动器具备 12 轮平滑检测的 Win32 `CloseMainWindow` 安全接手重启与前台置顶；
- **待切换状态机事务（Pending Switch Transaction）**：引入磁盘事务文件 `pending-switch.json`，遇到系统休眠、网络瞬断或断电时，守护神可在下次心跳毫秒级自愈接续拉起，自愈后自动销毁，实现 100% 无感自动续航。

### 2. Cockpit Tools 智能选号引擎（Cockpit Quota Engine）
- **5小时满血优先加权**：5 小时额度越充沛越优先，满血 (>=95%) 账号具有最高基础优先级；
- **周恢复时间紧迫度加权**：周重置时间越短越优先（如 1~2 天优先于 5~6 天），优先消耗即将过期的周存量；
- **严格一票否决**：周额度耗尽（<=5%）或 5 小时额度耗尽（<=5%）一票否决淘汰，彻底杜绝切入不可用账号。

### 3. 专线网络订阅状态透明化透出
- **实时健康度看板**：状态看板与守护日志实时输出三大机场订阅健康度（如：`已加载 31 条专线候选 (泡泡Dog: 16 | 三毛机场: 10 | 性价比机场: 5)`），彻底消除用户对“订阅是否更新”的疑虑。

### 4. 桌面极简与唯一权威入口
- 桌面仅保留单一权威入口 **`Antigravity 启动器.lnk`**，日常开工双击一次即可，其余全流程后台自动驾驶。

### 5. 开源代码仓库收拢（方案 A 达成）
- 本地 Git remote 全面重设并收拢至唯一官方公开仓库 `zwmopen/Antigravity-Windows-Recovery-Launcher`，云端冗余私有仓库已归档封存，保持纯粹单一开源真源。
