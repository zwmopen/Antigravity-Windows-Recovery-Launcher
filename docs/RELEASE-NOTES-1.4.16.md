# Antigravity Windows Recovery Launcher v1.4.16

## 核心更新

- 当前账号额度触发门禁时，先检查全部启用账号的周额度。
- 若全池周额度均为 0，立即停止自动切号、凭据写入、订阅刷新、关闭窗口和启动器重启。
- 首次进入耗尽状态时弹出桌面通知并记录结构化事件；持续耗尽期间静默等待，不重复刷屏。
- 任一账号周额度恢复后自动解除停止状态，重新允许正常接力。

## 验证

- 新增 `tests/quota-pool-exhaustion.test.py`。
- AccountWatcher、故障转移、启动时序、无感切换、安装器、启动器 UI、汉化与分享包隔离测试全部通过。
- 源码、构建目录和实机安装目录中的智能切号脚本 SHA-256 一致。
