# Antigravity 智能启动器 · 用户使用与跨设备分发手册

欢迎使用 **Antigravity 智能启动器 (Antigravity Recovery Launcher)**！
本文档专门解答如何在日常使用中获得最丝滑的编程体验，以及如何将软件分发给其他电脑开箱即用。

---

## 🚀 三分钟跨设备分发指南（给其他电脑使用）

如果你想把本启动器给朋友或在另一台电脑上使用，整个过程极其简单，无需复杂的配置：

### 步骤 1：确认目标电脑有可用订阅
* 目标电脑只需安装有 **Clash Verge Rev**、**Mihomo Party** 或 **Flclash** 中的任意一款；
* 在代理客户端中已正常导入好订阅节点并能正常上网即可；
* 💡 **不用关心 Clash 安装在哪个盘**（无论是 C 盘、D 盘还是其他目录），启动器会自动识别并提取节点！

### 步骤 2：选择任意一种分发包发送并解压/安装
你可以从 `releases/public/` 中选择以下任意一种交付形态发送给目标电脑：
* **形态 A：绿色免安装包（推荐便捷使用）**
  1. 将 `Antigravity-Windows-Recovery-Launcher-1.0.0-windows-x64.zip` 解压到目标电脑的任意目录（如 `D:\Tools\Antigravity`）；
  2. 双击运行解压出来的 `Antigravity-Recovery-Launcher.exe`（或者双击 `Install.cmd`）；
  3. 启动器在首次运行时会自动在桌面生成 **`Antigravity 启动器.lnk`** 快捷方式，并在后台注册自愈守护服务。
* **形态 B：标准安装向导包（适合小白用户）**
  1. 直接双击运行 `Antigravity-Windows-Recovery-Setup-1.0.0-windows-x64.exe`；
  2. 按照极简中文向导一路点击“下一步”，自动安装完成并生成桌面快捷方式。

### 步骤 3：从此只需双击桌面图标
以后每天写代码，**只要双击桌面上的 `Antigravity 启动器` 图标即可**，再也不需要任何命令行或繁琐设置！

## 🎯 核心日常使用体验

### 1. 冷启动（Antigravity 未启动时）
* 双击桌面图标后，启动器会弹出一张极具质感的胶囊验证窗口；
* 启动器自动从订阅池中匹配延迟最低、历史上最稳定的节点，并在后台完成 Google 204 网络握手与真实 Gemini 模型的极速探活；
* 验证通过后秒级拉起 Antigravity 编辑器，并自动完成界面全中文直译。

### 2. 热启动与窗口速切（Antigravity 已在后台运行时）
* 当你已经在写代码或最小化了窗口，再次双击桌面图标时，**绝不会强杀编辑器或重复多开进程**；
* 屏幕右下方会弹出一张精致的双态微型卡片：
  - **`进入代码窗口 (3s)`**：卡片带有 3 秒倒计时，倒计时结束后自动将已打开的编辑器窗口唤起并置顶到屏幕最前；你可以直接点击它立刻呼出窗口；
  - **`⚡ 切换最优专线`**：如果你感觉当前 AI 响应慢或者节点卡顿，点击此按钮，启动器会**在后台暗中热切换专线**，编辑器窗口不闪烁、不崩溃、写到一半的代码丝毫无损！

### 3. 后台全自动静默自愈（无感守护）
* 启动器内置了轻量级守护引擎（`Antigravity-AccountWatcher`），在后台每隔 20 秒静默感知專线健康度；
* 如果专线发生网络断流或因 Google 地区政策被拦截，守护引擎会自动在几百毫秒内完成专线漂移自愈，全程**不弹扰人弹窗、不杀编辑器进程**，为你提供真正免维护的心流环境。

## 💡 为什么不需要配置 Clash 安装路径？（底层原理人话解释）

很多用户会疑惑：“我的 Clash 装在 D 盘，别人的装在 C 盘，启动器怎么能找得到？”

**答案是：启动器要的核心根本不是 Clash 这个软件安装在哪里，而是你的“订阅节点数据”！**

1. **统一的系统规范**：
   无论把 Clash 软件本体安装在哪个盘，Windows 系统规范都严格要求其用户数据、订阅文件和节点缓存必须统一存放在当前用户的漫游应用目录 `%APPDATA%` 中；
2. **直击本质读取节点**：
   启动器直接读取标准路径下的订阅缓存，提取出所有可用的日本、美国专线节点，构建一个专属于 Antigravity 的独立 17897 隧道；
3. **内核雷达全盘自适应**：
   至于负责建立隧道的内核程序，启动器具备三级搜寻能力：即使装在特殊路径，启动器也会自动翻阅 Windows 系统的卸载安装注册表，精准定位内核位置。
   
**结论：零配置，开箱即用。**

## 🔒 独立沙盒：会影响我平时的代理或上网吗？

**完全不会！**
* 启动器为 Antigravity 专门开辟了一个独立的 `127.0.0.1:17897` 专属通道；
* 你平时日常使用的 Clash（通常是 7897 端口）依然保持原样，无论是规则模式、看网页还是打游戏，互相完全隔离、互不干扰；
* 启动器不会修改你系统的全局网络设置，更不会去改动你日常 Clash 里的选点。

## 🧹 如何干净卸载？

如果你需要移除启动器：
* **如果是 Setup 安装版**：直接在 Windows“设置” -> “已安装的应用”中找到“Antigravity 智能启动器”，点击卸载即可，自动清理快捷方式与自愈服务；
* **如果是绿色解压版**：双击运行目录下的 `uninstall.ps1`，即可一键卸载桌面入口与开机后台守卫。
* 卸载过程极为克制，**绝对不会删除你的 Antigravity 官方编辑器、代码工程、Git 仓库或个人配置数据**。
