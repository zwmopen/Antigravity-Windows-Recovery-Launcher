第三方与参考说明
================

本项目的汉化术语和界面覆盖范围参考了公开项目：
https://github.com/yuexps/Antigravity-Hans

当前检查时该仓库未提供明确 LICENSE 文件。因此，本项目没有复制其 Go 启动器、CDP 实现或静态补丁源码；运行时、打包、保护规则和性能优化均在本项目中独立实现。部分界面中文术语属于对同一 Antigravity 英文界面的功能性翻译。

若计划公开发布到 GitHub Releases、软件商店或用于商业分发，建议先联系上游作者确认词库授权，并为本项目补充明确的开源许可证。

本项目以 MIT License 发布。Mihomo 使用 MIT License；本项目不内置 Mihomo，只调用用户本机已有的兼容核心。Mihomo Party/Clash Party 使用 GPL-3.0，本项目不复制、链接或重新分发其源码，只读取用户本机配置缓存中兼容的 YAML 数据。

Google 官方 Antigravity CLI 当前仓库未声明可再分发许可证，因此本项目源码和 Release 不包含 `agy.exe`。安装脚本只从 Google 官方更新清单下载对应平台二进制，并要求官方 SHA-512 校验通过。

Google、Antigravity、Gemini 及相关名称和商标归各自权利人所有。本工具是非官方社区工具，与 Google 无隶属或认可关系。
