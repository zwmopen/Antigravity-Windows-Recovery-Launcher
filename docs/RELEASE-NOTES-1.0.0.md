## 🌟 核心突破与重磅特性

### 1. 彻底终结杀编辑器：无感热切换与后台自愈 (Seamless Hot Failover)
* **编辑器进程永不中断**：重构了自愈与手动切换架构。当后台检测到专线断流、节点失效或用户主动点击切换时，系统仅在 `127.0.0.1:17897` 独立沙盒内部进行上游节点的热漂移重路由，**绝对不再杀死 Antigravity 编辑器主进程**，彻底保护正在编写的代码与会话上下文；
* **循环自愈漏洞彻底根治**：修复了语言日志位置回绕导致的重复触发自愈缺陷，只有在真正发生网络截断或地区受阻时才会发起精准热修。

### 2. 首帧微任务同步直译：彻底告别设置面板 1 秒翻页闪烁 (Microtask Zero-Flicker)
* **DOM 挂载前置直译**：为设置面板（Settings Surface）和弹窗模态框注入 `isInstantUiNode` 微任务优先执行通道；
* **零延迟无感汉化**：节点进入 DOM 树的同一时钟周期内立即完成中英直译，彻底消除了从英文跳变到中文的“瞬间翻页撕裂感”，带来媲美原生客户端的丝滑体验。

### 3. 热启动极简双态胶囊卡片 (Hot Launch Capsule Card)
* **情境自感知**：当 Antigravity 已在后台运行时，双击桌面图标不再盲目拉起新进程或强制重启，而是弹出一张精致、轻量的微型卡片；
* **3 秒无感回归与极速救急**：左侧提供 **`进入代码窗口 (3s)`** 倒计时按钮，倒计时结束或点击后秒级置顶编辑器窗口；右侧提供 **`⚡ 一键重启修复`**，不仅支持平时一键重排最优网络专线，更在遇顽疾时支持一键彻底重置 Socket 连接池与坏节点冷却隔离。

### 4. 多客户端订阅自发现与绝对解耦 (Zero-Config Multi-Client Radar)
* **订阅与安装路径彻底解耦**：无论 Clash Verge Rev、Mihomo Party 安装在 C 盘、D 盘还是任何非标目录，启动器均穿透标准 `%APPDATA%` 自动读取订阅索引与节点缓存，真正实现“用户只需导入订阅，其它一概无需操心”；
* **三级内核智能搜寻雷达**：依次通过预设路径、系统 PATH 环境变量与 Windows 注册表 `Uninstall` 安装记录动态定位 mihomo 内核，开箱即用率 100%。

### 5. 跨电脑开箱即用与分发体系 (Turnkey Distribution)
* **绿色免安装版 (Zip)**：解压到任意电脑的任意目录，双击启动器即可运行，并在首次启动时自动在桌面生成快捷方式、自动接入开机自愈守护；
* **标准安装向导版 (Setup.exe)**：基于 Inno Setup 提供简洁中文安装向导，支持自由选择路径，卸载干净彻底。
