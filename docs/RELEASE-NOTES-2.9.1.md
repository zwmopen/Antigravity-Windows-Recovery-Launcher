## 🌟 核心突破与重要特性

### 1. ⚡ 内存重试死锁即刻熔断（彻底终结 429 卡死）
* **痛点根除**：过去当某个账号额度耗尽触发 429 报错时，底层的语言服务进程（`language_server.exe`）容易陷入长达 144 秒甚至 9 次的固执重试死循环。即使系统已在 Windows 凭据管理器换上了新账号，卡在内存里的旧进程也无法感知，导致用户界面停滞在“正在重试”。
* **秒级热重启熔断**：v2.9.1 在捕获到 429 报错的瞬间，不再做消极的重试等待，而是直接向语言服务发送优雅重启信号。上层客户端在 0.5 秒内原地重新拉起核心进程，瞬间读取满血账号凭据，会话原地复活，无需用户手动干预。

### 2. 🧠 四级智能算力调度算法（按周额度到期精准优选）
彻底终结过去“盲目切号”、“周额度即将清零却被闲置、反而去白白消耗新号”的算力浪费痛点：
* **第 1 优先级：周到期时间（越近越好）**：剩余 2 天到期的账号绝对优先于剩余 6 天到期的账号使用，杜绝即将刷新的额度被过期作废；
* **第 2 优先级：可用额度存量（>5% 且同梯队多者胜出）**：门槛需大于 5%（小于等于 5% 判定为濒死账号自动跳过），同到期梯队内额度更高者优先；
* **第 3 优先级：小时额度充沛（越满血越好）**：周额度相近时，优先调用 5 小时额度 100% 满血账号，保障高强度编码爆发力；
* **第 4 优先级：异常状态一票否决**：提示需申诉、需网页二次验证或封禁账号扣除 100,000 分直接出局，绝不踩雷。

### 3. 🛡️ 冷启动零信任前置门禁（Preflight Gate）
* **彻底根除启动即报错**：无论是开机后首次启动，还是关闭客户端后再次点击桌面快捷方式，启动器在拉起窗口前 **0.2 秒后台原子预检当前账号状态**。
* **坏号无感拦截自愈**：若检测到当前账号已耗尽、已封禁或需要网页验证，不等编辑器弹窗报错，直接在后台原子切换至最优健康账号再唤醒客户端，启动即用。

### 4. 🔓 动态账号黑名单隔离与一键解封（`--unblock` 闭环）
* **异常账号自动入库隔离**：遇到申诉或安全验证账号自动进入隔离看板，防止被调度系统重复误切。
* **一键四重解封**：用户在网页端申诉成功或解除验证后，只需在终端运行一条指令：
  ```bash
  .\Antigravity-QuickSwitch.cmd --unblock <邮箱>
  ```
  系统自动打通“硬黑名单移除 ＋ 429 临时关押池释放 ＋ Cockpit AES-GCM 加密账户重置 ＋ 界面状态刷新”，账号瞬间满血重返算力池。

### 5. 📸 极简视觉全景刷新：四行透明看板与双态交互
* **冷启动四行透明核验看板**：专线沙盒（17897）、Google 专线通路、Gemini 官方模型探针、算力账号调度四维状态一目了然；
* **热启动双态感知胶囊**：检测到编辑器运行时，桌面卡片提供“打开继续使用 (3s)”与“⚡ 网络自愈重连”，人话直觉，毫不干扰心流；
* **像素级渲染优化**：告别后台截屏异常，采用纯内存原生抗锯齿渲染，物料纤毫毕现。

## 🛠️ CLI 运维与状态速查指令

| 指令 | 作用与功能说明 | 适用场景 |
| :--- | :--- | :--- |
| `.\Antigravity-QuickSwitch.cmd` | **智能平滑切号** | 依据四级算法计算全局最优账号并无感热切换 |
| `.\Antigravity-QuickSwitch.cmd --force` | **强制轮换至最优号** | 忽略当前状态，直接切至当前排名第一的账号 |
| `.\Antigravity-QuickSwitch.cmd --blocked` | **查看账号隔离看板** | 一览所有被系统关押、硬黑名单的账号清单与原因 |
| `.\Antigravity-QuickSwitch.cmd --unblock <邮箱>` | **一键解封账号** | 申诉或解除验证成功后，将账号释放回归算力池 |
| `.\Antigravity-QuickSwitch.cmd --block <邮箱> "原因"` | **手动拉黑隔离** | 人工临时或永久隔离异常账号，防止被调度切入 |
| `.\Antigravity-QuickSwitch.cmd --preflight-ensure` | **冷启动门禁核验** | 预检当前账号状态，遇坏号时自动在后台秒级自愈切换 |
