## 🎯 v2.9.31 重大升级亮点

### 1. ⚡ 冷启动极速直通（“一次打开直接能用”，告别大池盲测）
* **痛点根治**：彻底消除此前每次开机冷启动由于端口未监听而强行触发 20 节点并发池盲测并导致反复碰壁、又退又进的问题；
* **极速秒开**：开机或代理退出后启动时，直接在 150ms 内冷复活拉起上次验证合格的专线配置并执行极速核验，通过后直接 **2~3 秒进入工作区**！

### 2. 🧠 “智能优选”稳定性第一 + 速度加权全闭环
* **彻底废除“纯 Ping 速度覆盖”**：
  建立以历史稳定度为主导的全新 `SmartScore`（0~1000 分）多维评估体系：
  - 历史通过白名单基础分 **+500**；
  - 当前在用 / 上次在用节点专属加成 **+200**；
  - 成功次数正向成长（每次成功 +25 分，最高累加 +250 分）；
  - 最近 24 小时内验证可用 **+120 分**；
  - 历史高分稳线（$\ge 700$ 分）在轮换分组前**直接置顶直通候选 1**。
* **速度加权胜负手**：
  当两条或多条线路稳定性一致时，按实测网络与模型延迟加权（$\le 100$ms 加 120 分，$100\sim 200$ms 加 80 分），确保永远排在第一位的是“最稳且最快”的优质线路。
* **越用越聪明的成长闭环（`Mark-NodeSuccess`）**：
  在极速直通与全量换线中全部接入成功写库闭环，只要线路实际通过模型门禁，成功次数自动递增，时间与延迟自动保鲜，备用梯队越积越厚。

### 3. 🛡️ 地区受限 IP 深度沉底与强力隔离
* 针对 Google 判定机房受限的节点（`model_location`），冷却隔离期延长至 **12 小时（720 分钟）**；
* 评分重罚 **-500 分**（得分直接跌至 100 分以下），彻底打入冷宫，绝不再占用宝贵的开机启动时间。

### 4. 🛑 取消激进预启动（彻底杜绝“界面开了还在换线”）
* 增加安全置信门禁：只有确定为历史高分稳线（$\ge 700$ 分）才在直通时前置预热；
* 凡是未知新节点或备选节点，推迟至第 4 步模型验证确实验真通过后，再点亮第 5 步拉起编辑器，杜绝错位乱象与崩溃。

### 5. 🤝 热启动文案与动作解耦（彻底解除误杀崩溃隐患）
* 热启动卡片主按钮固定为安全的 **“进入反重力 (5s)”**，点击或超时**只做窗口激活与置顶，彻底移除自动杀进程切号的逻辑**，杜绝点一下启动器导致正在聊天的编辑器闪退；
* 启动胶囊在第 5 步通过后，停留确认时间延长至 **1000ms（整整 1 秒）** 并醒目展示 `✔ 全部检测通过 · 工作环境已就绪`，消除突然关闭的迷惑感。

### 6. 🌐 Antigravity 2.32 界面与核心会话全面汉化（`v0.4.8`）
* 补齐对话头与操作（`Agent said` -> `智能体回复`、`You said` -> `您说`、`Agent working` -> `智能体工作中`、`Pinned Actions` -> `置顶操作`、`Conversation turns` -> `对话轮次`、`Undo to this point` -> `回退至此`、`Expand message` -> `展开消息`、`Collapse message` -> `折叠消息` 等）；
* 动态相对时间标签（`\d+[smhd] ago` -> `X分钟前/X天前`）、动态轮次（`Turn X of Y`）；
* 2.32 新特性与远程功能覆盖：通行密钥（`Passkeys`）、连接设备（`Connect a device`）、WSL 与 SSH 连接状态等。
