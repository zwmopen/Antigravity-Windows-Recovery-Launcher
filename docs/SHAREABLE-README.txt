Antigravity 中文助手 0.4.0
============================

用途
----
为 Windows 版 Google Antigravity 桌面客户端提供外部动态简体中文界面。
不修改 app.asar、preload.js、登录信息、会话、项目文件或网络代理。

系统要求
--------
1. Windows 10 或 Windows 11（64 位）。
2. 已安装官方 Antigravity 桌面客户端。
3. 当前主要适配并验证 Antigravity 2.11.0；官方更新后可能需要更新词库。

使用方法
--------
1. 完整解压 ZIP，不能只把 EXE 单独拖出来。
2. 双击 Antigravity-Chinese-Assistant.exe。
3. 点击“启动中文版”。
4. 首次切换前请保存 Antigravity 中正在编辑的内容；切换语言会关闭并重新打开客户端。

恢复英文
--------
打开助手，点击“恢复英文原版”。该操作不删除 Antigravity 数据，只是不加载汉化脚本并重新启动官方客户端。

创建快捷方式
------------
点击“创建桌面入口”，桌面会增加“Antigravity 中文助手”。删除该快捷方式不会删除任何数据。

卸载
----
1. 先点击“恢复英文原版”。
2. 关闭中文助手。
3. 删除解压出来的 Antigravity-Chinese-Assistant 文件夹和桌面快捷方式即可。

隐私与安全
----------
- 汉化只处理本地界面文字。
- 默认保护对话标题、消息、Markdown、代码、终端、编辑器和输入内容。
- 不上传数据，不安装后台服务，不设置开机启动，不修改系统或 Clash 代理。
- Windows 可能对未签名的小众 EXE 显示 SmartScreen 提醒。源码在项目 src 目录中，可自行构建和校验。

故障排查
--------
- 提示“未找到 Antigravity”：先安装官方桌面客户端；当前自动检测标准安装目录。
- 提示“汉化加载器缺失”：重新完整解压 ZIP，不要单独复制 EXE。
- 启动后仍是英文：关闭 Antigravity 和助手，重新打开助手再点“启动中文版”。
- 页面卡顿或混合语言：恢复英文，并反馈 Antigravity 版本和具体页面文字。
