# Antigravity Recovery Launcher v1.6.0 发布说明

> **发布日期**：2026-09-13  
> **版本**：v1.6.0 稳定版 (Watch Daemon v0.6.0)  
> **核心突破**：无缝热重启切号引擎 ＋ 4 会话 5 秒沉淀自动续接 ＋ 胶囊界面最小化

---

## 🌟 核心突破与重要特性

### 1. 🔥 无缝热重启切号引擎（编辑器窗口 0 闪退）
* **架构创新**：摒弃以往“为了换工牌把整栋饭店拆掉重建”的冷重启模式。自动切号时**不再关闭 Antigravity 编辑器窗口**，仅精准 Kill 底层语言模型核心（`language_server.exe`）。
* **秒级原地拉起**：Electron 前端在 2~3 秒内自动重新拉起核心进程，新进程在启动瞬间从 Windows 凭据管理器（`gemini:antigravity`）读取最新注入的满血账号 Token。
* **双重保险降级**：内置 25 秒超时自愈探测。若语言服务未能自动重拉，系统自动无缝回退至老版完整冷重启（启动器重拉），绝不卡死。

### 2. 🎯 4 窗口智能体自动续接与 5 秒沉淀机制
* **前排覆盖扩大**：自动续接范围由 3 个窗口正式扩展至**前 4 个会话窗口**，优先保护切号前的活跃任务。
* **5 秒加载沉降期**：通过 CDP 原生键入 `1` 之后，系统显式挂起等待整整 **5.0 秒**，等待 React 组件树挂载、Lexical 状态树绑定及发送按钮解除防抖，再派发回车提交，彻底根治回车吞噬。

### 3. 🖥️ 启动器胶囊界面最小化支持
* 在热启动与主自愈胶囊窗口右上角新增**极简胶囊最小化按钮（`-`）**；
* 支持点击最小化至任务栏，解决此前只能点击关闭或强行置顶遮挡屏幕的体验痛点。

### 4. 🛡️ 429 报错全池耗尽误判缺陷彻底修复
* 修复此前捕获到模型 429 报错时误将 `force_exhausted=True` 传给门禁函数导致全池 100% 满血账号被锁死不切号的致命 Bug；
* 解耦“当前账号耗尽”与“全池账号耗尽”，门禁状态自动解除并标绿。

### 5. ⚡ 专线网络零扰动保持
* 自动切号流程彻底跳过订阅刷新与节点重选，100% 复用已验证通畅的 17897 专线，切号全流程耗时从 4 分钟骤降至 **40 秒**。
